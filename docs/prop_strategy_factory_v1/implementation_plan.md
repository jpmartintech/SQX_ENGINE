Add split-safe 1/2/3/5/10/20-day vectors, timing/duration descriptors, lineage, and deterministic manifests. Gate: all fields reproducible and no General records changed.

Add Prop objective adapter and versioned grammar/exit configuration without changing General semantics. Gate: deterministic fitness and causal/negative controls.

Implement staged cheap-to-expensive promotion and reason codes. Gate: complete candidate accounting and cost robustness.

## Phase D — marginal utility

Implement frozen reference pools and bounded insertion tests. Gate: before/after metrics, reference hash, and reproducible utility vectors.

## Phase E — automatic handoff

Attach EconomicSpec, R ledger, ExecutionProfile, metadata, and PROP_READY status at promotion. Gate: Portfolio Factory consumes without backfill.

Run the first campaign against the General baseline with frozen splits. Gate: measurable metric deltas and no semantic/MQL5 regression before any larger search.
