# PROP_V1 promotion funnel

| Stage | Purpose | Required artifact |
|---|---|---|
| GENERATED | Candidate emitted with lineage | generation record |
| CAUSAL | No lookahead and deterministic evaluation | causal validation record |
| BASIC_EDGE | Basic edge/frequency/quality floor | trade/R ledger and reason codes |
| SHORT_HORIZON_QUALITY | 1–20D metric vector | short-horizon metrics |
| COST_ROBUST | Profile cost scenarios | cost sensitivity record |
| TEMPORAL_STABLE | Development/Validation stability | split report |
| NOVEL | Economic/timing novelty | behavioral descriptor |
| PORTFOLIO_USEFUL | Bounded marginal utility | reference-pool insertion report |
| PROP_READY | Complete handoff contract | EconomicSpec, ledger, manifest |

Thresholds are calibrated from existing policy and campaign distributions; they are not invented to force a target count. Every rejection has a machine-readable reason.
