# Versioning

Initial identifiers:

- `factory_lineage = PROP_V1`
- `prop_factory_version = 1.0.0-design`
- `prop_grammar_version = PROP_GRAMMAR_V1-design`
- `prop_fitness_version = PROP_FITNESS_V1-design`
- `prop_metrics_version = PROP_METRICS_V1`
- `economic_spec_version = UNIVERSAL_ECONOMICS_V1`
- `reference_portfolio_set = PROP_REFERENCE_SET_V1`
- `campaign_config = PROP_CAMPAIGN_V1`

Every strategy hash includes the canonical StrategyDefinition and lineage/version metadata. Campaign manifests include data hashes, split boundaries, seed, reference-set hash, and configuration hash.
