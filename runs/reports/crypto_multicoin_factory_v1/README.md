# Multi-Coin Strategy Factory V1

This report root contains the long-history M15 dataset audit and per-asset PRICE_ONLY factory expansion from `a1a4da7`.

Manufacturing used 50,000 unique Random plus 200,000 unique Genetic DEV evaluations per eligible non-BTC asset. Each asset was frozen before VAL and OOS; OOS is burned research only. No LOCKBOX was accessed. Multi-coin portfolio construction is deliberately deferred to the next product phase.

Start with `FINAL_REPORT.md`, `MULTICOIN_DATA_CATALOG.json`, `DATA_ACCESS_LEDGER.json`, and each `per_asset/<ASSET>/library_summary.json`.
